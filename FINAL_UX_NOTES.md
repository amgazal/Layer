# Layer — final usability pass

## First-time-user findings addressed

- Removed the duplicate **Plan a later time** control from the activity card. The only planning control now lives in **Heading out?**.
- Added a short explanation under **What’s the plan?** so users know activity choices change the recommendation.
- Renamed **Quick dash** to **Quick trip** for clearer everyday language.
- Removed chevrons from clothing rows because those rows were not interactive.
- Simplified the profile to the information users are most likely to care about: ratings, profile progress, local save status, cloud-sync status, and two clear actions.
- Renamed **Use device only** to **Turn off cloud sync** so the action is explicit.
- Added pressed-state semantics to planner and activity controls for accessibility.

No database migration or new environment variables are required.
