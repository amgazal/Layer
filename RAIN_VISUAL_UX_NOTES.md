# Rain visual and planner UX update

- Live rain now uses the current 15-minute observation plus the latest completed 15-minute interval.
- The app never substitutes a future 15-minute slot for the current condition.
- Rain and showers are considered alongside total precipitation without double counting.
- The scenic background follows the decoded live condition, so measured rain overrides an overcast WMO code.
- Active rain adds a waterproof layer directly to the clothing list and replaces the generic subheading with a direct rain instruction.
- Duration choices are now 20 min, 1 hr, 2 hrs, and 4+ hrs in an even grid (4 across desktop, 2×2 mobile).
